# ルーレットUI背景画像プロンプト（独立指示書）

以下を画像生成ツールに入力する。

```text
横長 600×250 ピクセル、PNG（背景は不透明）。ゲーム「Sephiria」のレトロなピクセルアートに合う、スロットマシン風ルーレットUIの背景パネルを描く。

正面から見た、古いカジノスロットマシンの内側パネル。左右対称で、平面的な2Dドット絵。キャンバス全体を背景パネルとして使い、外側の透明余白や外枠は作らない。ゲーム内で約300×125ピクセルに縮小して表示しても、色面と装飾が読み取れる大きさにする。

配色は暗いワインレッド、深い赤紫、焦げ茶を中心に、控えめな真鍮色と古びた金色を差し色にする。既存UIの明るい金色の外枠が画像の外側に別途表示されるため、この画像自体には太い外枠や金色の囲み線を描かない。内側に細い真鍮の飾り線を使う場合も、キャンバスの端から十分内側に置く。

上半分中央は、ゲーム内で3つのリール窓が重ねて表示される領域。ここは暗く落ち着いた無地に近い色面にし、絵柄や強い模様を置かない。下端中央は結果テキストが重なる領域なので、暗い赤紫のシンプルな帯にして、高コントラストの装飾を避ける。

空いた左右端と四隅に、昔のスロット筐体を思わせる小さな真鍮のリベット、細い幾何学模様、控えめな扇形の彫刻を左右対称に配置する。古びた塗装や金属の摩耗は、少数のはっきりしたピクセル色で表現する。全体は落ち着いたレトロ調で、中央のリール図柄と結果表示を見やすく保つ。

Sephiriaのドット絵に馴染む、輪郭のはっきりしたピクセルアート。限定色、明確な色の段差、アンチエイリアスなし、ぼかしなし、写真風・3D風・ベクター風ではない。文字、数字、ロゴ、記号、リール窓、図柄、ボタン、レバー、コイン投入口は一切描かない。画像の端まで背景色を塗る。
```
