# テスト用杖の画像に関する調査メモ

この資料はテスト用杖を検討した際の調査記録です。テスト用武器の登録・画像読み込みコードは現在削除されており、ここに記載した画像はMODから読み込まれません。生成指示書と完成画像は資料・素材として保持しています。

## 調査時点の想定

- テスト用の杖（武器種・進化1・進化2）は既存スタッフの `WeaponEntity` を複製する想定でした。
- 複製元と同じ見た目で動作確認するだけなら、独自画像は不要です。
- 独自の見た目を実装する場合に必要な画像を、以下に記録します。

## 必要になる画像

武器ごと（武器種・進化1・進化2のそれぞれ）に用意します。

| 用途 | 対応するフィールド | 内容 |
|---|---|---|
| 小アイコン | `WeaponEntity.icon` | 武器選択画面・図鑑の一覧に出るアイコン。 |
| 大アイコン | `WeaponEntity.bigIcon` | ツールチップや詳細表示に出る大きいアイコン。 |
| 武器本体の見た目 | `mainWeaponPrefab` 内のスプライト | プレイヤーが装備したときに表示される杖の画像。 |
| 攻撃エフェクト | `WeaponSimple_Staff.basicAttackFx` など | 通常攻撃時のエフェクト（独自にする場合のみ）。 |

## 画像の仕様

- 形式は PNG（透過あり）を想定します。
- ゲームはドット絵なので、拡大縮小で補間されないよう、ドット絵のまま作ります。
- 公式ガイドのコスチューム例では、キャラクターのスプライトは 20×16 ピクセルです。
- 武器アイコンと武器本体の寸法は、下の「ゲーム内スタッフ画像の実測」を参照してください。ゲームの素材そのものは再配布しないでください。

## ゲーム内スタッフ画像の実測

### 画風

- 杖は縦向き（先端が上）で、左右対称です。
- シャフトは 1〜2px の細い線で、上下の両端に飾りがあります。
- 全体を 1px の黒い輪郭線が囲みます。
- 色は少なく、シャフトは暗い茶色か灰色です。属性ごとに先端の色（炎は橙、氷は水色、雷は白と青、特殊は金）が変わります。
- 段階が上がるほど、横に広がる飾りや十字の装飾が付き、幅と高さが増えます。
- 影やグラデーションはなく、ハイライトは明るい1〜2色のドットで表します。

## 画像の作り方（img_md フォルダ）

画像生成用の指示は、`docs/` ではなく `img_md/<武器名>/` に置きます。

1. `img_md/01テスト用杖/` に、画像1枚につき1つの md を置きます（`01_武器種_本体.md` ～ `07_大アイコン.md`）。
2. 各 md には、サイズ、コンセプト、構図、各部分の描写、色、質感を書きます。
3. md の内容を画像生成ツールへ渡して、透過PNGを作ります。
4. 生成後、指定サイズ（例: 5×32 px）に最近傍補間で縮小し、半透明のピクセルが残っていないか確認します。
5. この資料に記録された画像読み込み処理は現在削除されています。再実装する場合は下の「実装上の注意」を参照してください。

## 実装上の注意

- 当時の実装では完成画像を `package/images/` に置き（`tier0_body.png` / `tier0_icon.png` ～ `tier2_*`、`big_icon.png`）、MOD起動時に `Entry.cs` から読み込んで `icon` / `bigIcon` に設定していました。この処理は現在削除されています。
- 当時の実装では武器本体用に複製元プレハブの最大スプライトを差し替え、`RegisterNetworkPrefab(prefab, stableKey)` で登録していました。NetworkManager が未初期化の場合はデータベース準備完了・タイトル画面表示のイベントで再試行していました。

- 公式APIには、武器の画像をファイルから差し替える仕組みは用意されていません。
- 差し替える場合は、MODフォルダの PNG を `Context.ResolvePath` で読み込み、`Sprite.Create` で作ったスプライトを `icon` / `bigIcon` に設定するコードが必要です。
- 武器本体の見た目は、複製元のプレハブを複製して `SpriteRenderer` のスプライトを差し替える必要があり、ネットワークプレハブとしての登録（`RegisterNetworkPrefab`）が要る可能性があります。今回は未検証です。
- 画像ファイルは `package/` 側に置かないとビルド後にMODフォルダへコピーされません。
